# Search Log Guidance

For every database or platform, record:

- database/platform;
- exact execution date;
- exact field scope;
- complete query string;
- raw result count;
- exported result count;
- deduplication contribution;
- notes about platform-specific limitations.

The current repository preserves the search-log information available in the cumulative workbook. Any field not present in that source must be completed from the original export history rather than inferred.

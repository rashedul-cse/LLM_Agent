# Repository and Evidence Limitations

1. The corpus is bounded and terminology-driven; it is not an exhaustive PRISMA census.
2. Seven candidate records lacked usable full text before the evidence cut-off.
3. The primary screening and coding were completed by one author.
4. The repository contains quantified role and boundary sensitivity but no genuine second-coder reliability statistic.
5. Thirty of 39 core studies are preprints; one is a peer-reviewed workshop paper and eight are peer-reviewed papers.
6. Exact database execution dates and raw hit counts are not complete in the current records.
7. Some 2026 bibliographic metadata may change after the evidence cut-off.
8. Study-reported quantitative results are not pooled because threat models, memory systems, models, and metrics are heterogeneous.
9. The provisional MEIRC retrospective mapping requires page-level verification before it is treated as a final manuscript table.
10. Reviewed full-text PDFs are not redistributed.
